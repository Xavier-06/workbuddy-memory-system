# Memory (HOT Tier)

> 高价值经验规则（HOT = High-value, Ongoing, Tested）。每条规则都经过验证，可以反复使用。

## 使用方法

每次发现可复用的经验（不是犯错，而是"这样做更好"）时，写入此文件。

格式：

```markdown
## HOT: {{规则名称}}

**场景：** {{在什么情况下这条规则适用}}

**规则：** {{具体怎么做}}

**Why：** {{为什么这条规则有效}}
```
