# Memory (HOT Tier)

> 高价值经验，每次任务前必须检查。按主题分组。

## Preferences

- 称呼：怎么叫用户 / 叫 AI 什么
- 沟通风格：简洁/详细/幽默/正经
- 执行风格：先看再做 / 边做边看

## Patterns

- 有 skill 就用 skill
- 做新任务前先扫描已有工具
- 修改配置后同步所有相关位置

## Rules

- **先看再建**：接受任务时，先扫描目标系统的已有代码和结构，再决定是嵌入还是重写。默认嵌入。
- **Skill 优先**：任何任务开始前，检查可用 skill 列表。有 1% 可能性相关就必须加载。
- **Self-reflection 必做**：完成多步骤任务后，记录教训到 corrections.md。
- **全自动必须真全自动**：只有从输入自动跑到最终交付（含失败重试/状态推进/结果发送）且无需用户催促时，才能叫全自动。否则老实说是半自动。

> 格式说明：每个 Rule 写一句话规则 + 必要时补充 Why/How to apply
