# corrections.md

> 用户纠正的记录。格式：日期 + 犯错描述 + 纠正 + 抽象规则。

## 使用方法

每次被用户纠正时，立即写入此文件。不要事后补。

格式：

```markdown
## [YYYY-MM-DD] {{犯错场景}}

**问题：** {{当时怎么理解的}}

**纠正：** {{用户说应该怎么做}}

**规则：** {{抽象成一条可复用的规则}}
```
