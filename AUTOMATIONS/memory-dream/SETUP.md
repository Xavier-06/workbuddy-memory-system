# 自动化：每日记忆蒸馏（Dream）

**作用**：每天凌晨自动把旧每日日志蒸馏成主题记忆，保持记忆系统精简不过时。

## 工作流程

```
每天凌晨 2:00 自动触发
    │
    ▼
扫描 ~/.workbuddy/memory/ 下的每日日志
    │
    ▼
识别 > 7 天未处理的日志
    │
    ▼
蒸馏精华到对应主题文件
    │
    ▼
删除已被吸收的原日志
```

## 在 WorkBuddy 中配置

### 创建自动化任务

1. 打开 WorkBuddy
2. 创建新自动化任务
3. 设置触发条件：
   - 类型：定时触发
   - 时间：每天凌晨 2:00
4. 设置任务内容：执行蒸馏逻辑（见下方）

### 蒸馏逻辑（让 AI 执行）

1. 扫描 `~/.workbuddy/memory/YYYY-MM-DD.md` 每日日志
2. 识别连续 7 天以上的日志
3. 从每篇日志中提炼：
   - 新的项目决策 → 更新 project_*.md
   - 用户偏好变化 → 更新 user_profile.md
   - 新的外部系统 → 新建 reference_*.md
   - 有效的做法 → 更新 ~/self-improving/memory.md（HOT 规则）
4. 提炼完成后删除已被吸收的日志
5. 更新 MEMORY.md 索引（新增/删除的条目）

## 与 extractMemories 的区别

| | Dream（蒸馏） | extractMemories（提取） |
|---|---|---|
| 触发时间 | 每天凌晨 | 每天早上 |
| 处理对象 | 老日志（>7天） | 新日志（当天/昨天） |
| 动作 | 蒸馏 + 删除原日志 | 提炼到主题文件 + 保留日志 |
| 目标 | 保持记忆系统精简 | 积累新知识 |

Dream 负责"减肥"，extractMemories 负责"吸收"。

## 静默退出原则

- 没有超过 7 天的日志 → 静默退出
- 日志内容已被现有主题文件覆盖 → 静默退出

## 注意事项

- **并发保护**：配合 consolidation-lock.sh 防止与 extractMemories 同时运行
- **增量进行**：不要试图一次蒸馏所有历史日志，每次只处理最早的那批
- **保留近期**：7 天内的日志不蒸馏，留给 extractMemories 处理
