# 自动化：会话摘要更新

**作用**：每 8 小时更新 session-summary.md，确保下次接上。不漏掉上次做到哪了。

## 工作流程

```
每次会话结束（AI 检测到对话告一段落）
    │
    ▼
读取 MEMORY.md 和 session-summary.md
    │
    ▼
验证所有主题文件存在性（无悬空指针）
    │
    ▼
更新 session-summary.md：
- 更新时间戳
- 记录本次会话做了什么
- 记录下次需要继续的工作
```

## 在 WorkBuddy 中配置

### 触发条件

- **触发时机**：每 8 小时定时触发
- **不是**：每次用户发消息就触发

### 任务内容

让 AI 执行以下操作：

1. 读取 `~/.workbuddy/memory/MEMORY.md`
2. 读取 `~/.workbuddy/memory/session-summary.md`
3. 验证 MEMORY.md 中引用的所有主题文件存在（无悬空指针）
4. 更新 session-summary.md：
   - 更新时间戳
   - 补充本次会话做了什么
   - 标注下次需要继续的工作

## session-summary.md 模板

```markdown
# 会话摘要

> 本文件记录每次会话的关键信息，供下次接续使用。

## 最近会话

**时间：** YYYY-MM-DD HH:MM
**用户：** {{用户名}}
**主要工作：**
- {{任务1}}
- {{任务2}}

## 待续工作

- {{下次需要继续的任务1}}
- {{下次需要继续的任务2}}

## 注意事项

- {{需要记住的重要事项}}
```

## 验证是否正常运行

检查 session-summary.md：
- 时间戳是否最新
- 待续工作是否有更新
- 无悬空指针（所有引用文件都存在）
